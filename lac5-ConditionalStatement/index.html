JavaScript Conditional Statements: Conditional statements are used to execute different blocks of code based on whether a condition is true or false.

if Statement: The if statement executes a block of code only when the given condition is true.

Example: if (age >= 18) { console.log("You are an adult"); }

if-else Statement: The if-else statement executes one block when the condition is true and another block when the condition is false.

Example: if (age >= 18) { console.log("Adult"); } else { console.log("Minor"); }

else-if Statement: The else if statement is used when we need to check multiple conditions.

Example: if (marks >= 90) { console.log("A"); } else if (marks >= 75) { console.log("B"); } else if (marks >= 50) { console.log("C"); } else { console.log("Fail"); }

Multiple Conditions: Logical operators such as &&, ||, and ! can be used to combine multiple conditions.

Example: if (age >= 18 && age <= 60) { console.log("Eligible"); }

Nested if: A nested if statement means placing one if statement inside another if statement.

Example: if (age >= 18) { if (hasId) { console.log("Allowed"); } }

Ternary Operator: The ternary operator is a short way to write a simple if-else condition.

Syntax: condition ? valueIfTrue : valueIfFalse

Example: let result = age >= 18 ? "Adult" : "Minor";

switch Statement: The switch statement is used when we want to compare one value with multiple possible cases.

Example: switch (day) { case "Monday": console.log("Start of the week"); break; case "Sunday": console.log("Weekend"); break; default: console.log("Other day"); }

case: The case keyword defines a possible value that JavaScript checks inside a switch statement.

break: The break statement stops the execution of the current switch case or loop.

default: The default block executes when none of the cases match the given value.

Truthy Value: A truthy value behaves like true when used in a condition.

Examples of commonly truthy values: "Hello", 10, true, [], and {}.

Falsy Value: A falsy value behaves like false when used in a condition.

Common falsy values are: false, 0, -0, "", null, undefined, and NaN.

Truthy/Falsy Example: JavaScript automatically converts a value to Boolean when it is used directly as a condition.

Example: let username = "Sanu"; if (username) { console.log("Username exists"); }

Conditional Expression: Conditions can be combined using logical operators to create more complex decisions.

Example: if (username && password) { console.log("Login successful"); }

Nullish Coalescing Operator: The ?? operator provides a default value when the left side is null or undefined.

Example: let username = null; let name = username ?? "Guest";

Optional Chaining: The ?. operator safely accesses a property when an object may be null or undefined.

Example: user?.address?.city

Conditional Flow: JavaScript checks conditions from top to bottom. Once a matching condition is found in an if-else if-else chain, its block is executed and the remaining conditions are skipped.

Example: if (marks >= 90) { console.log("A"); } else if (marks >= 60) { console.log("B"); } else { console.log("C"); }

if-else vs switch: Use if-else when you need to check ranges or complex conditions. Use switch when comparing one value against multiple specific values.

Conditional Statements Summary: The main conditional concepts in JavaScript are if, if-else, else if, nested if, switch, and the ternary operator.
