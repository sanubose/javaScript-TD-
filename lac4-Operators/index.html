JavaScript Operators: Operators are symbols used to perform operations on values and variables.

Arithmetic Operators: Arithmetic operators are used to perform mathematical calculations.

+ Addition — adds two values. Example: 10 + 5 → 15

- Subtraction — subtracts one value from another. Example: 10 - 5 → 5

* Multiplication — multiplies two values. Example: 10 * 5 → 50

/ Division — divides one value by another. Example: 10 / 5 → 2

% Modulus — returns the remainder after division. Example: 10 % 3 → 1

** Exponentiation — raises a number to a power. Example: 2 ** 3 → 8

++ Increment — increases a value by 1. Example: x++

-- Decrement — decreases a value by 1. Example: x--

Assignment Operators: Assignment operators are used to assign or update values in variables.

= Assigns a value. Example: x = 10

+= Adds a value and assigns the result. Example: x += 5 is the same as x = x + 5

-= Subtracts a value and assigns the result. Example: x -= 5

*= Multiplies and assigns the result. Example: x *= 5

/= Divides and assigns the result. Example: x /= 5

%= Performs modulus and assigns the result. Example: x %= 5

**= Performs exponentiation and assigns the result. Example: x **= 2

Comparison Operators: Comparison operators compare two values and return a Boolean value: true or false.

== Equal to — compares values after type conversion if necessary. Example: 5 == "5" → true

=== Strictly equal to — compares both value and data type. Example: 5 === "5" → false

!= Not equal to — checks whether values are different. Example: 5 != 3 → true

!== Strictly not equal to — checks value or data type difference. Example: 5 !== "5" → true

> Greater than. Example: 10 > 5 → true

< Less than. Example: 5 < 10 → true

>= Greater than or equal to. Example: 10 >= 10 → true

<= Less than or equal to. Example: 5 <= 10 → true

Logical Operators: Logical operators are mainly used to combine or reverse conditions.

&& Logical AND — returns true when both conditions are true. Example: age >= 18 && age <= 60

|| Logical OR — returns true when at least one condition is true. Example: age < 18 || age > 60

! Logical NOT — reverses a Boolean value. Example: !true → false

?: Ternary Operator — a short way to write a simple if-else condition. Example: age >= 18 ? "Adult" : "Minor"

?? Nullish Coalescing Operator — returns the right-side value when the left-side value is null or undefined.

Example: let name = username ?? "Guest";

?. Optional Chaining Operator — safely accesses a property or method when an object may be null or undefined.

Example: user?.address?.city

typeof — returns the data type of a value. Example: typeof "Sanu" → "string"

instanceof — checks whether an object belongs to a particular constructor or class. Example: arr instanceof Array → true

Bitwise Operators: These operators work with numbers at the binary/bit level.

& Bitwise AND

| Bitwise OR

^ Bitwise XOR

~ Bitwise NOT

<< Left Shift

>> Sign-propagating Right Shift

>>> Zero-fill Right Shift

+ can also be used as a String Concatenation Operator. It joins strings together.

Example: "Hello " + "Sanu" → "Hello Sanu"

... Spread Operator — expands the elements of an array or properties of an object.

Example: let arr2 = [...arr1];

... Rest Operator — collects multiple values into an array inside function parameters or destructuring.

Example: function sum(...numbers) { }

delete — removes a property from an object.

Example: delete user.age;

in — checks whether a property exists in an object.

Example: "name" in user → true

new — creates a new object from a constructor or class.

Example: const user = new Person();

Operator Precedence: When multiple operators are used in one expression, JavaScript follows a specific order to decide which operation happens first.

Example: 2 + 3 * 4 → 14 because multiplication is performed before addition.
