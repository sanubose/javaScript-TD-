String: A String is used to store text or a sequence of characters.

Number: A Number is used to store numeric values, including integers and decimal numbers.

Boolean: A Boolean has only two values: true or false. It is mainly used for conditions.

Undefined: Undefined means a variable has been declared but no value has been assigned to it.

Null: Null represents an intentional absence of a value.

BigInt: BigInt is used to store very large integer numbers.

Symbol: Symbol is used to create unique values, mainly for unique object properties.

Object: An Object stores data in key-value pairs.

Array: An Array is used to store multiple values in a single variable.

Function: A Function is a reusable block of code that performs a specific task.
