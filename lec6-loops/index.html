JavaScript Loops: Loops are used to execute the same block of code repeatedly while a condition is true or for each item in a collection.

Why Use Loops: Loops help us avoid writing the same code repeatedly. Instead of writing the same statement many times, we can use a loop to execute it automatically.

Example Without Loop: console.log(1); console.log(2); console.log(3); console.log(4); console.log(5);

Example With Loop: for (let i = 1; i <= 5; i++) { console.log(i); }

Types of Loops: JavaScript provides several types of loops, including for, while, do...while, for...of, and for...in.

for Loop: The for loop is used when you know how many times you want to execute a block of code.

Syntax: for (initialization; condition; update) { // code }

Example: for (let i = 1; i <= 5; i++) { console.log(i); }

How the for Loop Works: First, initialization runs once. Then the condition is checked. If the condition is true, the loop body executes. After that, the update expression runs. This process continues until the condition becomes false.

for Loop Flow: The execution order is: initialization → condition → code → update → condition → code → update.

Example: for (let i = 1; i <= 3; i++) { console.log(i); }

Output: 1 2 3

while Loop: The while loop executes a block of code repeatedly as long as the specified condition is true.

Syntax: while (condition) { // code }

Example: let i = 1; while (i <= 5) { console.log(i); i++; }

Important: In a while loop, you must make sure that the condition eventually becomes false. Otherwise, the loop can become an infinite loop.

Example: let i = 1; while (i <= 5) { console.log(i); i++; }

do...while Loop: The do...while loop executes the code block first and checks the condition afterward.

Syntax: do { // code } while (condition);

Example: let i = 1; do { console.log(i); i++; } while (i <= 5);

Special Feature of do...while: A do...while loop always executes at least once, even when the condition is initially false.

Example: let i = 10; do { console.log(i); } while (i < 5);

Output: 10

for...of Loop: The for...of loop is used to iterate over the values of iterable objects such as arrays, strings, maps, and sets.

Example with Array: let fruits = ["Apple", "Mango", "Banana"]; for (let fruit of fruits) { console.log(fruit); }

Output: Apple Mango Banana

for...of with String: The for...of loop can also iterate over each character of a string.

Example: let name = "Sanu"; for (let character of name) { console.log(character); }

for...in Loop: The for...in loop is mainly used to iterate over the enumerable property keys of an object.

Example: let user = { name: "Sanu", age: 28, city: "Sitapur" }; for (let key in user) { console.log(key); }

Output: name age city

Access Object Values: You can use the key obtained from for...in to access the corresponding object value.

Example: for (let key in user) { console.log(user[key]); }

for...in vs for...of: for...in gives property keys or indexes, while for...of gives the actual values of an iterable.

Array Example: let fruits = ["Apple", "Mango", "Banana"]; for (let index in fruits) { console.log(index); } for (let fruit of fruits) { console.log(fruit); }

break: The break statement immediately stops the loop and moves execution to the code after the loop.

Example: for (let i = 1; i <= 10; i++) { if (i === 5) { break; } console.log(i); }

Output: 1 2 3 4

continue: The continue statement skips the current iteration and moves to the next iteration of the loop.

Example: for (let i = 1; i <= 5; i++) { if (i === 3) { continue; } console.log(i); }

Output: 1 2 4 5

Nested Loop: A nested loop is a loop placed inside another loop. It is commonly used for tables, grids, patterns, and matrix operations.

Example: for (let i = 1; i <= 3; i++) { for (let j = 1; j <= 3; j++) { console.log(i, j); } }

Infinite Loop: An infinite loop is a loop that never becomes false and continues running indefinitely.

Example: while (true) { console.log("Running"); }

Warning: Avoid infinite loops unless they are intentionally controlled, because they can freeze or slow down the application.

Loop with Array: Loops are commonly used to process every element of an array.

Example: let numbers = [10, 20, 30, 40]; for (let i = 0; i < numbers.length; i++) { console.log(numbers[i]); }

Loop with Condition: A loop can contain an if statement to perform different operations based on each value.

Example: for (let i = 1; i <= 10; i++) { if (i % 2 === 0) { console.log(i); } }

Output: 2 4 6 8 10

Reverse Loop: A loop can run in reverse by starting from a larger value and decreasing the counter.

Example: for (let i = 5; i >= 1; i--) { console.log(i); }

Output: 5 4 3 2 1

Loop with Function: A function can contain a loop, or a loop can call a function during each iteration.

Example: function printNumber(number) { console.log(number); } for (let i = 1; i <= 5; i++) { printNumber(i); }

Loop with User Input: Loops can be used to repeatedly process user input until a particular condition is satisfied.

When to Use for Loop: Use a for loop when you know the number of iterations or when you need a counter.

When to Use while Loop: Use a while loop when the number of iterations is not necessarily known and execution depends on a condition.

When to Use do...while: Use do...while when the code must execute at least once before checking the condition.

When to Use for...of: Use for...of when you want to directly access the values of an iterable such as an array or string.

When to Use for...in: Use for...in mainly for iterating over object property keys.

Loop Comparison: for is useful for counter-based loops, while is useful for condition-based loops, do...while executes at least once, for...of iterates over values, and for...in iterates over object keys.

Loop Control Statements: JavaScript provides break to stop a loop and continue to skip the current iteration.

Loops and Performance: Loops are efficient for repetitive operations, but unnecessary or very large loops can affect application performance. Always avoid doing expensive work repeatedly when it is not necessary.

Modern Array Iteration: JavaScript also provides array methods such as forEach(), map(), filter(), and reduce() for processing arrays.

forEach(): Executes a function once for each array element.

Example: numbers.forEach(function(number) { console.log(number); });

Important: forEach() cannot be stopped early using a normal break statement.

Loop Summary: JavaScript loops allow us to repeat code efficiently. The main loops are for, while, do...while, for...of, and for...in.

Important Loop Keywords: break stops a loop, continue skips the current iteration, and return exits the entire function when used inside a function.
