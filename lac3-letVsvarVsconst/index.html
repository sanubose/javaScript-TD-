var vs let vs const

JavaScript mein variables declare karne ke liye mainly var, let aur const ka use hota hai.

1. var

Scope: Function Scope

Agar var ko kisi function ke andar declare kiya hai, to wo poore function ke andar accessible hota hai.

Re-declaration

var name = "Sanu";
var name = "Bose";

console.log(name); // Bose

var ko same scope mein dobara declare kar sakte hain.

Re-assignment

var age = 25;

age = 26;

console.log(age); // 26

var ki value change kar sakte hain.

Block Scope

{
  var city = "Sitapur";
}

console.log(city); // Sitapur

var block scoped nahi hota. Isliye block ke bahar bhi access ho sakta hai.

2. let

Scope: Block Scope

let sirf us block { } ke andar accessible hota hai jisme usse declare kiya gaya hai.

Re-declaration

let name = "Sanu";

// let name = "Bose"; ❌ Error

Same scope mein let ko dobara declare nahi kar sakte.

Re-assignment

let age = 25;

age = 26;

console.log(age); // 26

let ki value ko change kar sakte hain.

Block Scope Example

{
  let city = "Sitapur";

  console.log(city); // Sitapur
}

console.log(city); // ❌ Error

Block ke bahar let variable accessible nahi hota.

3. const

Scope: Block Scope

const bhi let ki tarah block scoped hota hai.

Re-declaration

const name = "Sanu";

// const name = "Bose"; ❌ Error

Same scope mein const ko dobara declare nahi kar sakte.

Re-assignment

const age = 25;

age = 26; // ❌ Error

const variable ko re-assign nahi kar sakte.

const ko value dena compulsory hai

const name = "Sanu"; // ✅

// const age; ❌ Error

const declare karte time value deni zaroori hai.

var vs let vs const

Feature var let const
Scope Function Block Block
Re-declare ✅ Yes ❌ No ❌ No
Re-assign ✅ Yes ✅ Yes ❌ No
Hoisting Yes Yes Yes
Temporal Dead Zone ❌ No ✅ Yes ✅ Yes

4. Hoisting

JavaScript execution se pehle variable declarations ko memory mein register karta hai. Is behavior ko hoisting kehte hain.

var

console.log(x); // undefined

var x = 10;

var hoist hota hai aur initially undefined milta hai.

let / const

console.log(x); // ❌ ReferenceError

let x = 10;

let aur const hoist hote hain, lekin declaration se pehle access nahi kiye ja sakte. Is period ko Temporal Dead Zone (TDZ) kehte hain.

5. Kab kya use karein?

const

Jab variable ko re-assign nahi karna hai, normally const use karo. 

const name = "Sanu";
const age = 28;

let

Jab variable ki value future mein change karni hai, let use karo. 

let score = 0;

score = 10;
score = 20;

var

Modern JavaScript mein generally var avoid kiya jata hai. Ye mostly purane JavaScript code mein milta hai.

6. Sabse important rule 🧠

  1. Pehli preference: const
  2. Agar value change karni hai: let
  3. var ko modern JavaScript mein generally avoid karo. 
const name = "Sanu";  // value change nahi hogi

let age = 28;         // value change ho sakti hai
age = 29;

// var old JavaScript code mein zyada milta hai
